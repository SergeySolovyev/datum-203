# Datum

Обзор 204 компаний, у которых история оценки DCF совпадает с историей цены, ещё 2 компаний без класса (отдельной группой), и лента их карточек Datum.

- `index.html` — обзор (таблица, клик по строке открывает карточку);
- `lenta.html` — лента карточек;
- `c/<тикер>.json` — содержимое карточек.

Аналитический материал, не инвестиционная рекомендация.
