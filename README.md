# Datum

Обзор 233 компаний и лента их карточек Datum: у 208 история оценки DCF совпадает с историей цены, у 25 компаний совпадение оценки с ценой слабое, оценок слишком мало для сравнения или модели не дали оценку.

- `index.html` — обзор (таблица, клик по строке открывает карточку);
- `lenta.html` — лента карточек;
- `c/<тикер>.json` — содержимое карточек.

Аналитический материал, не инвестиционная рекомендация.
