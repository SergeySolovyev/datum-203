# Datum 203

Обзор 203 компаний, у которых история оценки DCF совпадает с историей цены, и лента их карточек Datum.

- `index.html` — обзор (таблица, клик по строке открывает карточку);
- `lenta.html` — лента карточек;
- `c/<тикер>.json` — содержимое карточек.

Собрано `build_feed.py` из опубликованного снимка pilot2000. Аналитический материал, не инвестиционная рекомендация.
